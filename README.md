# AI CFO Platform

An AI-powered financial intelligence platform for startups and SMEs.

The platform helps businesses analyze financial data, forecast cash flow, simulate business scenarios, and generate AI-driven CFO insights for strategic decision-making.

---

## Core Features

- Financial statement upload and analysis
- Cash flow forecasting
- Runway calculation
- Scenario simulation
- Expense anomaly detection
- AI-generated financial insights
- Automated board report generation
- Interactive analytics dashboard
